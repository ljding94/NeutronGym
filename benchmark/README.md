# McStasBench — benchmark harness & data

The held-out benchmark slice of NeutronGym: task definitions, the observable-based
grader, and the headless episode runner. **Code lives in `harness/`; everything
else in this folder is data.** Results never land here — every run writes to the
top-level `runs/` (gitignored).

## Layout

| Path | What it is | Committed? |
|---|---|---|
| `harness/` | all benchmark code (see below) | yes |
| `tasks/` | task definitions as JSON, by tier: `P*` pilots/probes, `T1/` reproduce, `T2/` improve-to-target, `T3/` open design; `T1/_validation.json` records self-validation | yes |
| `instruments/` | committed reference instruments: T2 baselines (`build_t2_instruments.py` — task inputs), `heldout/` (references we authored — never public before this repo; `build_heldout_tasks.py`), `perturbed/` (contamination-control variants; `perturb_tasks.py`) | yes |
| `contamination/` | per-model memorization-probe records (temperature-0, provider-pinned; `probe_memorization.py --all`) | yes |
| `t2_baseline_arms.json` | the T2 table's baseline columns: initial / classical / random-search FOMs re-verified at 1e8 + fresh seed (`t2_baseline_arms.py`) | yes |
| `inventory.json` | the curation registry: machine-verified paper↔`.instr` candidate pool (which references run here, `%Example` agreement, triage notes) | yes |
| `tasks.html` | human-friendly task catalog — generated by `python3 scripts/tasks_report.py`, **never hand-edited** | yes |
| `refcache/` | per-task cached reference-run summaries (the grading ground truth), built on first grade and reused | no — gitignored, regenerable |

## The harness (`harness/`)

Run everything with `conda run -n mcstas python ...` from the repo root.

**Daily drivers:**

- `run_episode.py` — the entry point: one task id (or path) → one agent
  episode → graded report.
  `python benchmark/harness/run_episode.py T1_PSI_DMC
  [--scaffold loop|claude|oneshot] [--model <id>] [--provider Google]
  [--no-skill] [--episode-dir DIR]`
  Scaffolds: `loop` = the NeutronGym reference loop (default, the
  measurement instrument), `claude` = headless Claude Code comparison arm,
  `oneshot` = plain-LLM baseline (no tools). Every episode is sandboxed
  (server benchmark mode, Read deny rules, mandatory leak audit stamped as
  `reference_leak`), provider-pinned, discovered-artifact graded under the
  env-controlled protocol, and shipped with the `artifacts/` visual bundle.
  Output: `runs/pilot/<task>__<scaffold>__<model>/`.
- `leak_audit.py` — sandbox layer 3: transcript scan for reference-leak
  tool calls (both arms' transcript formats); a leaked episode is INVALID.
- `visualize.py` — shared diagram/trace renderer: episode `artifacts/`
  bundles + `--refs` batch (reference visuals into `runs/refviz/`,
  thumbnails in `tasks.html`).
- `grader.py` — grade any `.instr` directly, no agent:
  `python benchmark/harness/grader.py <task.json> --candidate <file.instr> [--params k=v ...]`
- `validate_tasks.py` — curation gate: every task's reference must pass its own
  contract at a fresh seed; T2 baselines must FAIL unimproved.

**Task manufacturing (run in this order when growing the set):**

- `build_inventory.py` — sweep candidate instruments, verify they run here,
  write `inventory.json`.
- `author_tasks.py` — T1 tasks from inventory entries: NL spec-sheet prompts
  derived from the reference + auto-derived grading contracts.
- `build_t2_instruments.py` — generate the parameterized T2 baseline
  instruments into `instruments/`.
- `calibrate_t2.py` — set T2 targets from the constraint-filtered,
  fresh-seed-re-verified classical best (winner's-curse guard lives here).
- `build_heldout_tasks.py` — author the held-out tier: references built
  HERE from published instrument descriptions (BOYA, VENUS), same
  spec-sheet/contract pipeline, self-validated.
- `perturb_tasks.py` — contamination-control variants of seen tasks: one
  hard-coded parameter perturbed, accepted only with the pair-proof
  (perturbed reference self-passes AND the canonical file fails).

**Contamination + measurement records:**

- `probe_memorization.py` — memorization probe; `--all --model <id>` runs
  every scored task's reference (temperature 0, provider-pinned) and
  commits the per-model record to `contamination/`.
- `t2_baseline_arms.py` — re-verify the T2 classical arms at 1e8 rays +
  fresh seed (>3σ bar) into `t2_baseline_arms.json`.
  (The old `measure_fast_tier.py` is absorbed into the env executor +
  `neutrongym-eval`.)

## Grading principles (enforced by the code, summarized here)

Grade the artifact the agent built, never its claims · observable-based checks
(intensity, peak, CoM, FWHM) with statistics-aware tolerances and hard-failure
gating · reference and candidate always compared under the same env-controlled
protocol (ncount + seed set by the task, never by the agent) · any selected
best re-verified at a fresh seed · no LLM judge anywhere in T1/T2.
